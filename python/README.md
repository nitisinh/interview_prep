# Python Interview Prep

This directory contains coding problems, solutions, and practice materials for interview preparation.

## Directory Structure

- **problems/** - Problem statements and starter templates
- **solutions/** - Implemented solutions with explanations
- **notes/** - Algorithm notes, concepts, and study materials

## Getting Started

### Setup

1. Create a virtual environment:
```bash
cd python
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

2. Install dependencies (if needed):
```bash
pip install -r requirements.txt
```

### Running Tests

To run tests for a solution:
```bash
python -m pytest solutions/problem_name_test.py -v
```

## Coding Standards

- Use meaningful variable names
- Add docstrings for functions
- Write clean, readable code
- Include test cases
- Comment non-obvious logic
